# Cyber Heat Radar / サイレーダー

Cyber Heat Radar / サイレーダーは、サイバーセキュリティ関連の話題を「温度感」で整理する公開レポートです。

個別ニュースを単に列挙するのではなく、いま優先して把握すべき話題、継続して注目すべき話題、記録に残すべき低温トピックを分けて掲載します。

## このリポジトリの見方

- **最新レポート**: 直近で生成された通常レポートです。
- **日次レポート**: 1日複数回生成される通常レポートの履歴です。
- **四半期・半期・年次レポート**: 期間内で特に温度感が高かった話題、長く注目された話題を振り返る集計レポートです。
- **評価方式**: 温度感や音声掲載の考え方を説明します。

## 注意事項

Cyber Heat Radar は、日々の情報収集を補助するためのレポートです。  
個別組織のリスク判断や対応優先度を直接決定するものではありません。
